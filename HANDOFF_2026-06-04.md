## Code Changes Made Today

- Preserve fractional FPS from `v4l2-ctl` capability probing instead of truncating values like `7.5` to `7`.
- Allow camera settings and idle framerate settings to parse/save fractional FPS values.
- Render camera detail framerate options from the selected `format + resolution`, not global `COMMON_FRAMERATES`.
- Normalize direct/stale settings POSTs against cached camera capabilities before restarting FFmpeg.
- Show a warning when a submitted format/resolution/framerate combination is coerced.
- Refresh cached capabilities when known cameras reconnect or are found by manual scan.
- New install schema uses `REAL` for framerate fields. Existing SQLite installs can still store real values in old columns because of SQLite typing.

## Next Useful Work

3. Consider a camera-mode recommendation UI:
