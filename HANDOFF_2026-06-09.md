## Moonraker Extra Data Shape

Ravens Perch now advertises this namespaced metadata on each Moonraker webcam:

```json
{
  "ravens_perch": {
    "schema_version": 1,
    "camera_id": "3",
    "path": "3",
    "streams": {
      "webrtc": { "url": "http://printer:8889/3/", "protocol": "webrtc" },
      "rtsp": { "url": "rtsp://printer:8554/3", "protocol": "rtsp" },
      "hls": { "url": "http://printer:8888/3/", "protocol": "hls" },
      "snapshot": { "url": "http://printer/cameras/snapshot/3.jpg?token=<redacted>", "protocol": "http" }
    }
  }
}
```

The normal Moonraker `stream_url` remains WebRTC for browser frontend compatibility.
